# Release Notes — Version 2.0.0

**Release Date:** August 30, 2026  
**Build Status:** Stable & Production Ready  
**Branch:** `main`

---

## 🌟 Highlights of v2.0.0

Version 2.0.0 is a major milestone release focused on architectural modularity, full-system documentation, accessible light mode, and performance optimization across the entire Osmyka platform.

---

## 🚀 Key Improvements & Additions

### 1. Docusaurus Documentation & Knowledge Hub
- Integrated standalone technical documentation portal (`/docs/`).
- Hierarchical guides for AutoBook, CRM, Turnkey Web, Architecture, Releases, and APIs.
- Dedicated engineering blog and changelog system.
- Full Osmyka brand identity sync (Dark `#050912` / Light `#f8fafc`, Inter / JetBrains Mono fonts).

### 2. Modular CSS & JavaScript Architecture
- Decomposed monolithic stylesheet into clean, decoupled component modules in `css/components/`:
  - `tokens.css`, `base.css`, `buttons.css`, `cards.css`, `badges.css`, `forms.css`, `nav.css`, `mockups.css`, `tables.css`, `footer.css`.
- Structured client-side JavaScript into the global `window.Osmyka` modular registry with isolated lifecycle management (`Theme`, `Nav`, `ActiveNav`, `SmoothScroll`, `Reveal`, `Counters`, `CardsTilt`, `HeroWidget`, `Previews`, `ContactForm`).

### 3. Accessible Harmonious Light Theme
- Complete WCAG AAA compliant light theme palette.
- 0ms FOUT (Flash of Unstyled Theme) blocking script in `<head>`.
- Animated sun/moon toggle button with `localStorage` and system `prefers-color-scheme` listeners.
- Dynamic canvas particle palette update without restarting the animation loop.

### 4. Custom Branded SVG Vector Icons
- Designed bespoke SVG vectors for flagship product cards (`autobook`, `crm`, `managed`) incorporating Osmyka's signature node-and-circuit motif.
- Replaced technical stack tags with consumer value tags highlighting 24/7 cloud access, multi-level backups, secure databases, and responsive cross-device support.

### 5. Canvas Performance Optimization
- Resolved layout thrashing on mouse movement by caching container bounding rects.
- Added zero-overhead idle pausing when tabs are hidden or hero is scrolled out of viewport.

---

## 📦 Upgrading to v2.0.0

No breaking database or API changes. The upgrade is completely backwards-compatible with v1.0.0 client installations.
